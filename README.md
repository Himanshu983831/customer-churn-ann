# 📊 Customer Churn Prediction using ANN

A Machine Learning project that predicts whether a customer is likely to churn using an Artificial Neural Network (ANN).

## 🚀 Project Overview

Customer churn refers to customers leaving a service or company.

This project uses an Artificial Neural Network to analyze customer information and predict:

- ✅ No Churn
- ⚠️ Churn

The model is integrated with a Streamlit web application for interactive predictions.

## 🧠 Machine Learning Model

**Algorithm:** Artificial Neural Network (ANN)

**Problem Type:** Binary Classification

**Output:**
- Churn
- No Churn

### Model Workflow

Customer Data  
↓  
Data Preprocessing  
↓  
Feature Encoding  
↓  
Feature Scaling  
↓  
Artificial Neural Network  
↓  
Churn Probability  
↓  
Churn / No Churn
